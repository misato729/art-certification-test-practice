## 作成と確認の方針

- 時代・材料・制作工程・美術制度の関連付けを問い、作者名の想起だけに偏らない構成です。
- 調査記録、展示計画の数値、搬入時の場面は学習用の仮定です。実在する調査・展示基準・事故の記録ではありません。
- 図版の転載はなく、文章と独自の表で解ける問題です。資料に見られる画像比較・6択などをそのまま再現せず、サイトの4択形式に合わせています。
- 問題と解説の事実関係は2026年10月30日に美術館・博物館・公的保存機関の公開一次資料で確認し、別担当も正答の一意性と出典を照合しました。
- 10問だけで全範囲を網羅したり、本試験の出題比率・配点・難易度を再現したりするものではありません。

## 出典

各問の`source_text`を参照してください。技法・美術史はメトロポリタン美術館、京都・東京・奈良の国立博物館、太田記念美術館、国立国会図書館などの解説を参照しました。現代美術はシカゴ現代美術館、美術館建築は各館の沿革、展示・保存はカナダ保存研究所の資料を参照しています。

提供された参考資料の原本・作業画像・全文抽出物は`past-exam/`でローカル保管し、Git・Docker・外部公開の対象へ含めません。進捗記録には原文・図版を転載しません。

## 初期取込

問題の正本は初期取込後のDBです。このJSONを編集しても既存の問題は自動更新されません。現在の作業環境ではアプリ用の`.env`・稼働プロセス・Compose環境がないことを確認し、既存DBのリセットや上書きは行っていません。新しい空DBの起動時に10問を取り込みます。既存サービスへ適用する場合は[カスタマイズ手順](../docs/customization.md)に沿って、バックアップと対象DBを確認してから更新してください。
