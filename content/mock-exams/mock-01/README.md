# 模擬試験1

美術史問題80問と知識・情報の活用問題5問を一体として60分で解く、独自作成の85問です。サイトでは「模擬試験1」と表示し、試験番号1の1セットとして収録します。問題冊子23ページ、解答・解説25ページです。実践問題は含みません。

## 冊子

- [問題冊子・解答用紙](../../../output/pdf/art-grade2-mock-01-questions.pdf)
- [解答・解説・出典](../../../output/pdf/art-grade2-mock-01-answers.pdf)

PDFの表紙・ヘッダーも「模擬試験1」に統一しています。PDFは従来の通し問題番号1〜85のままです。今回のサイトの大問・小問への階層化は格納構造と表示上の番号を変更するもので、リード文と設問を組み合わせた問題本文・選択肢・正答・解説・出典は維持しています。PDFの改稿・再生成は行っていません。

美術史は4択、活用は最初に参照した問題集抜粋を参考にした編集上の構成として6択とし、いずれも正答は一つです。後から提供された公式Webサンプルでは活用にも4択の例があるため、6択を公式試験の固定形式とは説明しません。各問1点・85点満点で自己採点できます。51問正解は正答率60％の学習上の目安で、公式の固定合格点・配点ではありません。

提供された概要2ページと問題集抜粋11ページを分析しました。抜粋内の美術史37問・活用2問から、共通資料を使う小問、年代・技法・作品と作者・社会背景の関連付け、作品比較や根拠の照合という設問の特徴を参考にしています。抜粋は本試験の全問・複数年度の統計ではないため、上の配分は概要の範囲を広く含めるための編集上の設計です。

共通資料・表・設問・選択肢・解説は独自作成しています。原資料の文章・図版は転載していません。図版なしの文章・表版のため、作品画像の識別力や本試験と同じ実測難度・所要時間は検証していません。難易度分類も作問上の目安で、受験者の正答率データによるものではありません。

初版PDF作成後に追加された公式Webサンプル・正答資料・2025年実践問題も参照しました。Webサンプルは美術史24問と活用2問で、画像からの作品・図像・様式の識別、共通の複数作品と鑑賞記述を照合する問いを確認しています。サンプルから本試験全体の配分や難易度の統計は算出しません。2025年実践10問は別枠の資料として扱います。今回の85問に正答変更や一意性修正を要する矛盾は確認されなかったため、問題本文と正答は維持し、参照範囲と制限を説明・冊子へ反映しています。

活用問題は複数の美術史情報を関連付ける内容です。保存作業や美術館の運営実務を判断する別枠の実践問題とは分けています。事実関係の確認には美術館・博物館などが公開する一次資料を使い、各問の解説と出典を収録しています。

## 問題データ

- `questions.json`：`schema_version: 2`の模擬試験・大問・リード文・小問、選択肢・単一正答・解説・出典。表示ブロックと問題の形式は共有Zodスキーマに従います。
- `manifest.json`：時間、区分別の選択肢、配分、学習用採点方法、検証用設定、階層の件数、適用範囲。
- `editorial.json`：各問の題材、作問上の難易度、従来の共通資料のまとまり、大問・小問と通し番号の対応。

検査はリポジトリのルートで `node --experimental-strip-types scripts/check-mock-exam.mjs` を実行します。区分ごとに選択肢設定を切り替え、アプリ・運用CLIと同じ `frontend/shared/schemas/` で全問を検証します。独自の別スキーマは作っていません。

サイトへの組み込み依頼を受け、問題番号の区分ごとの選択肢数に対応しました。本フォルダの独立した85問も、サイトの `content/questions.json` に収録する85問も、試験番号1です。リード文参照を解決した本文・選択肢・正答・解説・出典の一致は共有スキーマを使う検査で照合します。

## 模擬試験・大問・小問とリード文

サイトの問題は「模擬試験1 → 大問 → 小問」として扱います。85問を23大問にまとめ、もともと共通の導入文があった12大問・43小問では、その文を1件のリード文へ分離しました。小問はリード文を参照します。残る11大問には新しいリード文を作らず、見出しと従来の設問本文を使います。

`question_number`の1〜85は教材・履歴・既存参照のための通し番号として保持します。`group_number`が大問番号、`group_question_number`が大問内の小問番号です。4択・6択の区分は従来どおり通し番号1〜80／81〜85で解決し、大問とは別に管理します。

共通リードは、従来の各設問の先頭ブロックから完全一致で取り出したものです。リード文と小問本文の再構成で元の全85問の本文が一致し、350選択肢・正答・解説・出典も変更していないことを確認します。参照用のIDは同梱ファイル内の対応付けに使うもので、既存DBの問題・選択肢IDを採番し直す指定ではありません。

サイトでは1問ずつ回答して採点・解説を見る演習形式です。60分の一括受験・最後にまとめて採点するセッション機能は含みません。初期取込後の問題の正本はDBで、同梱JSONの更新は既存DBへ自動反映しません。空DB限定importと開発環境限定seedを維持しています。今回の実装・検証は[検証記録](../../../docs/verification.md)を参照してください。

原資料・抽出物・分析の詳細はGitとDockerから除外されたローカル専用領域に保管しています。変更の検証・コミット・送信の実施状況は[検証記録](../../../docs/verification.md)を参照してください。サイトの公開や本番DBへの反映とは区別します。
