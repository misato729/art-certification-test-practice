## 出典と作問

改訂版『西洋・日本美術史の基本』美術検定1・2・3級公式テキスト（提供版：2026年5月8日・改訂版第13刷、ISBN978-4-568-24063-4）、『知る、わかる、みえる 美術検定2級問題 応用編』（提供版：2025年6月10日・第3刷、ISBN978-4-568-24084-9）を主な参考資料としました。テキスト本文・ポイント・作例データと、問題集の設問形式・解説を照合しました。文章版から継続した54問は書籍の参照ページを記録し、図版へ改訂した31問は別作品に対応する所蔵館の作品記録・公開一次資料を主な根拠として記録しています。

出典リンクは[主催団体の公式書籍案内](https://www.bijutsukentei.com/coverage)です。リンク先に書籍本文を公開しているわけではありません。一部の補足事項は美術館等の一次資料でも照合し、当該問題の出典へ追記しました。

設問・選択肢・共通資料・表・解説は独自作成です。原資料の問題文、選択肢の組合せ、図版は転載していません。作品名・歴史的事実・基本用語は出題範囲に応じて扱います。今回の図版改訂では31問を差し替え、文章版の54問を維持しました。

公式問題集の活用問題は5題材・13小問で、3択・4択・6択の例があります。今回の模試は5つの独立した資料照合問題を作り、全問4択へ統一しました。資料から判断できることと、追加資料が必要な推論も区別して問います。

## データと構成

85問・340選択肢を31大問に整理し、22件の共通リード文を76問が参照します。問題内の表は7件、図版は35点・36回の掲載です。

- `questions.json`：共有Zodスキーマに従うv2形式。配信用の `content/questions.json` と同一です。
- `manifest.json`：区分、配分、時間、参照資料の構成、適用範囲。
- `editorial.json`：題材、作問上の難易度、大問・小問の対応、各問の根拠ページ。`source_refs` の `fact` は事実関係、`format` は設問形式を参考にしたページです。`printed_page` は書籍のノンブル、`pdf_page` は提供スキャンの1始まりページ番号で、今回の2冊ではPDF番号がノンブル＋2です。

検査は `node --experimental-strip-types scripts/check-mock-exam.mjs` と共有スキーマを用います。美術史80問の正答位置はア・イ・ウ・エ各20問に分散しています。正答の一意性、解答を隠した独立試解、誤答の妥当性は構造検査とは別に確認します。

## 採点と適用範囲

各問1点・85点満点の学習用配点です。51問正解は60％の復習目安で、公式の固定合格点・配点や合格保証ではありません。難易度区分は基礎19・標準53・発展13という作問上の見積もりで、受験者データから校正したものではありません。

図版を用いる31問は画像の観察・識別・比較を必要とします。保護期間が残る現代作品の画像は扱わないため、全時代の画像識別練習には本アプリの限界があります。受験者による60分の解答時間の実測は行っていません。

サイトは1問ずつ採点する演習形式です。同梱データの更新は既存DBの更新を意味しません。初期取込は空DB限定で、既存の学習履歴や本番データをこの作業では変更しません。検証の実施状況は [検証記録](../../../docs/verification.md) を参照してください。

提供PDF、ページ画像、OCR、作問途中の資料はローカル専用の保護領域に保持し、Git・Docker・外部ストレージへ送信しません。
