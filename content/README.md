# 模擬試験1の問題データ

サイト用の`questions.json`には、試験番号1の「模擬試験1」1セット・全85問を収録しています。美術史問題80問は4択、知識・情報の活用問題5問は6択で、正答は各問一つです。本文・表・選択肢・正答と誤答の解説・公開一次資料の出典を含みます。

分野配分、問題冊子、解答・解説、参照資料と作問方針は[模擬試験1の説明](mock-exams/mock-01/README.md)を参照してください。同フォルダの独立した85問データとサイト用データは、いずれも試験番号1で、本文・選択肢・正答・解説・出典は同じです。PDFも名称を「模擬試験1」へそろえ、問題内容を維持しています。

## 形式と参照範囲

- サイトでは1問ずつ回答して、採点・解説・出典を確認します。60分の一括受験・一括採点セッションは含みません。
- 美術史の4択・活用の6択は、このセットの編集上の構成です。公式Webサンプルには活用の4択例もあり、6択を公式の固定形式とは説明しません。
- 独自の文章と表で解く構成です。提供資料の原文・図版は転載せず、作品画像の識別力や本試験の分野配分・実測難度・所要時間を再現したとは説明しません。
- 美術館・博物館などの公開一次資料を確認し、各問の`source_text`に出典を収録しています。
- 提供された原本・作業画像・全文抽出物は`past-exam/`にローカル保管し、Git・Docker・外部公開の対象へ含めません。

## 初期取込

初期取込後の問題の正本はDBです。新しい空DBには85問・350選択肢を取り込みます。このJSONを更新しても既存DBの問題は自動更新されず、リセット・上書き・自動削除は行いません。

既存DBへの反映は、[カスタマイズ手順](../docs/customization.md)に沿ってバックアップと対象DBを確認してから別途行います。今回実施した検証やコミット・送信の状況は[検証記録](../docs/verification.md)を参照してください。
