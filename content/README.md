# 同梱のサンプル問題

`questions.json`はテンプレートの動作確認用に作ったオリジナルの6問です。実在する資格試験の出題範囲・難易度・合格基準を表すものではありません。

| セット・問 | 内容 | 正答 |
| --- | --- | --- |
| 1・1 | 12個を3人で等しく分ける | イ：4個 |
| 1・2 | 「箱の中なら青い」という条件の適用 | ウ |
| 1・3 | 200円の25％引き | エ：150円 |
| 2・1 | 3ずつ増える数列 | ア：14 |
| 2・2 | 4・6・8の算術平均 | イ：6 |
| 2・3 | 三者の前後関係 | ウ：P → Q → R |

`source_text`の「動作確認用の架空出典」と`https://example.com/sample-content`は、出典表示の動作を確認するためのダミーです。実際の根拠資料へつながるURLではありません。資格向けの問題へ差し替えるときは、確認した実際の資料名と出典URLへ置き換えてください。

問題ファイルの形式・安全な初期取込・既存DBの扱いは、[カスタマイズ手順](../docs/customization.md)を参照してください。
