# 模擬試験1〜5の問題データ

サイト用の`questions.json`には、試験番号1〜5の「模擬試験1」〜「模擬試験5」、計425問を収録しています。各回は美術史80問と知識・情報の活用5問の85問、全問4択・正答一つです。本文・図版・表・解説・出典を含みます。

[全5回の構成・原稿・PDF](mock-exams/README.md)を参照してください。各回の独立データとサイト用データは、本文・選択肢・正答・解説・出典が一致します。模擬試験1の原稿・図版・PDFは保持し、2〜5に別の作品と具体的な出題の焦点を割り当てています。

## 形式と参照範囲

- 各回60分、全85問。実践問題10問・30分は含みません。サイトは1問ずつ採点する演習で、一括受験セッションは含みません。
- 全問4択は本サービスの編集上の構成です。公式問題集の活用には選択肢数の異なる例もあり、公式の固定形式とは説明しません。
- 各回の分野配分は西洋41・日本25・現代5・東洋3・工芸デザイン4・美術館2・活用5。難度の編集配分は基礎19・標準53・発展13です。実際の知識・判断・近接誤答・図版と読む量を比較し、受験者による統計的な等化とは区別します。
- 各回で美術史26問と活用5問に図版を用います。模試1は35作品、2〜5は各36作品で、全179作品・180配置。原作の日本での保護期間と所蔵館のCC0画像条件を別々に確認します。公式問題集と同一の図示作品は避けています。
- 保護期間が残る現代作品の図版を扱わないため、識別練習の範囲には限界があります。本試験の実測難度・合格点・所要時間の再現とは説明しません。
- 各問の`source_text`と編集メタデータに根拠を記録し、図版の出典と利用条件は各回の`image-manifest.json`へまとめています。
- 提供原本は`past-exam/`・`textbook.*`、作業資料は`local-only/`などにローカル保管し、Git・Docker・外部公開へ含めません。

## 初期取込

初期取込後の問題の正本はDBです。新しい空DBには425問・1700選択肢を取り込みます。JSONの更新は既存DBを自動更新せず、リセット・上書き・自動削除を行いません。

既存DBへの反映は、[カスタマイズ手順](../docs/customization.md)に沿ってバックアップと対象DBを確認してから別途行います。今回の検証、Git送信と公開の実施範囲は[検証記録](../docs/verification.md)へ記録します。
