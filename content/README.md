# 模擬試験1の問題データ

サイト用の`questions.json`には、試験番号1の「模擬試験1」1セット・全85問を収録しています。美術史問題80問と知識・情報の活用問題5問はいずれも4択で、正答は各問一つです。本文・図版・表・選択肢・正答と誤答の解説・根拠資料の出典を含みます。

分野配分、問題冊子、解答・解説、参照資料と作問方針は[模擬試験1の説明](mock-exams/mock-01/README.md)を参照してください。同フォルダの独立した85問データとサイト用データは、いずれも試験番号1で、本文・選択肢・正答・解説・出典は同じです。公式テキストと公式問題集全体を参考に全85問を作り直し、PDFも更新しています。

## 形式と参照範囲

- サイトでは1問ずつ回答して、採点・解説・出典を確認します。60分の一括受験・一括採点セッションは含みません。
- 全85問を4択にそろえた、このセットの編集上の構成です。公式問題集の活用には選択肢数が異なる例もあり、4択を公式の固定形式とは説明しません。
- 美術史26問と活用5問は図版必須で、35作品のCC0画像を使います。公式問題集の図版とは別作品を採用し、日本で作品の保護期間満了も確認しています。保護期間が残る現代作品の画像は扱わず、識別練習の範囲には限界があります。本試験の分野配分・実測難度・所要時間の再現とは説明しません。
- 公式テキストの該当箇所と必要な根拠資料を確認し、各問の`source_text`と編集用メタデータに出典を収録しています。
- 提供された原本・作業画像・全文抽出物は`past-exam/`にローカル保管し、Git・Docker・外部公開の対象へ含めません。

## 初期取込

初期取込後の問題の正本はDBです。新しい空DBには85問・340選択肢を取り込みます。このJSONを更新しても既存DBの問題は自動更新されず、リセット・上書き・自動削除は行いません。

既存DBへの反映は、[カスタマイズ手順](../docs/customization.md)に沿ってバックアップと対象DBを確認してから別途行います。今回実施した検証やコミット・送信の状況は[検証記録](../docs/verification.md)を参照してください。
